# ADR-004: More Than Brows como cliente piloto

**Fecha:** 2026-09-24

**Estado:** aceptada

## Contexto

ReservArte se construye para venderse a varias organizaciones. Hacía falta un centro real que anclara las decisiones de producto, y la auditoría señalaba que, tras meses de backend, seguía sin saberse si el sistema es lo que ese centro necesita.

## Decisión

More Than Brows es el cliente piloto y ha delegado en Guillermo las decisiones de producto.

## Alternativas descartadas

No quedó registrada una alternativa descartada.

## Consecuencias

Las dudas de producto se resuelven con Guillermo, no con un comité del centro. El piloto no convierte a More Than Brows en el único inquilino del modelo multi-tenant.
