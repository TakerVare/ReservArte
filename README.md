# ReservArte

Repositorio para la solución completa de gestión multi-tenant para centros de diseño de cejas. Documentación técnica en `Documentation/`. Stack previsto (memorias): **ASP.NET Core 8**, **Vue 3 + Vite** (web), **React Native** (móvil), **SQL Server en Docker**, **AWS**, **Cloudinary** (imágenes), **Redsys**. Autenticación: **Identity** (local + **login social** OIDC) y **JWT** para la API.
